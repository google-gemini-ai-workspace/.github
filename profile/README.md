## Troubleshooting Common Issues

Install issues? Refresh the session and clear cookies if the side panel does not appear in Docs or Gmail.  
Performance problems? Shorten the prompt and attach the file directly when answers miss the source material.  
License/activation? Check the Workspace licence and admin settings if connected sources are unavailable.  
Compatibility? Disable browser extensions that intercept page content when the panel behaves oddly.  
Update failures? Re-upload images in a common format if analysis fails silently.
